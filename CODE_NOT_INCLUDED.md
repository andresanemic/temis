# Code not included

This repository is a public review package for TEMIS: it contains the project explanation, testnet receipts, token records and legal limits. It does not contain TEMIS source code. The project materials describe the code as opening during the Find Your Way and Meridian judging period so judges and the community can read and clone it for evaluation.

That boundary matters when reading the evidence. The public transaction hashes and receipts let a reader inspect testnet activity and understand what the tests report. They are not a substitute for source review, and this documentation does not claim that the public repository is independently reproducible end to end without the code and the full history archive.

When code is made available, the stated purpose is review and evaluation under the repository's [review-only license](LICENSE). That license is proprietary, is not approved by the Open Source Initiative, and is a working draft that needs review by a lawyer. Read its actual terms before cloning or using any code. This page does not grant rights beyond the license.

## Qué código no está incluido

Este repositorio es un paquete público de revisión de TEMIS: contiene la explicación del proyecto, recibos de testnet, registros del token y límites jurídicos. No contiene el código fuente de TEMIS. Los materiales del proyecto describen que el código se abrirá durante el periodo de evaluación de Find Your Way y Meridian para que el jurado y la comunidad puedan leerlo y clonarlo con fines de evaluación.

Este límite importa al leer la evidencia. Los hashes y recibos públicos permiten inspeccionar actividad en testnet y entender qué informan las pruebas. No reemplazan una revisión del código, y esta documentación no afirma que el repositorio público permita reproducir de punta a punta el sistema sin el código y el archivo completo del historial.

Cuando se publique el código, el propósito declarado es su lectura y evaluación bajo la [licencia de solo revisión](LICENSE) del repositorio.
