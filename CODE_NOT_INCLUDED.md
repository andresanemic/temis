# Code not included

This repository currently contains project documentation and evidence, not TEMIS source code. The public release is intended to let the Find Your Way and Meridian judges and the community understand and review the project before its code is opened. The code will be published during the judges' review period under the review-only license in [LICENSE](LICENSE).

# Código no incluido

Este repositorio contiene por ahora documentación y evidencia del proyecto, no el código fuente de TEMIS. Esta publicación permite que el jurado de Find Your Way y Meridian y la comunidad entiendan y revisen el proyecto antes de abrir su código. El código se publicará durante el periodo de revisión de los jueces bajo la licencia de solo revisión de [LICENSE](LICENSE).
